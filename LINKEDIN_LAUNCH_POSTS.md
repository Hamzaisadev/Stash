## Post 10: The Build-in-Public Founder Story
> **Audience:** Software engineers, CTOs, indie hackers, tech recruiters.  
> **Goal:** Showcase technical mastery, architecture decisions, and open-source mindset.

### 📝 Post Copy
```markdown
How we built a real-time, zero-login file sharing & screen casting platform from scratch 🛠️

When building Stash (stash-ed.vercel.app), we focused on 3 core technical principles:

1️⃣ **Direct Peer-to-Peer with Cloud Fallback**:
Using WebRTC DataChannels, devices transfer files directly peer-to-peer at LAN speeds without touching server bandwidth. If a peer drops offline, Supabase Storage seamlessly takes over as the buffer.

2️⃣ **Stateless Cryptographic Access Tokens**:
Without requiring user accounts, how do you secure private rooms? We implemented HMAC-SHA256 token signing on room keys, allowing instant authorization without database session bloat.

3️⃣ **Chromium WebM Seek Scan Workaround**:
Browser audio recording with `MediaRecorder` often results in `Infinity` duration metadata. We engineered a rapid seek-scan trick on metadata load to compute accurate waveforms instantly.

Frontend: React, Vite, Tailwind CSS, Lucide Icons
Backend: Express, WebSockets (Socket.io), WebRTC, Supabase

Check out the live app: https://stash-ed.vercel.app
Source code & architecture docs: https://github.com/Hamzaisadev/Stash

I’d love your feedback on the architecture and real-time performance! 🚀

#buildinpublic #fullstack #javascript #reactjs #webrtc #nodejs #opensource #supabase
```
